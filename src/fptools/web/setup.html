配置自己的 Key

本工具默认使用内置的共享体验 Key——可用但额度有限、高峰可能限流（429）。 申请自己的 AppID 后额度充足、互不影响，全程免费（非商业用途）。

1

注册开放平台，获取 AppID

打开 open.winmale.com， 微信扫码登录（注册即送免费额度）。

右上角「我的」→「开放平台」→ 左侧「我的应用」→「查看应用信息」， 复制 client_id 和 api-key（即 client_secret）。

2

写入本机凭证文件（推荐）

创建 ~/.finpipe/credentials.env，内容两行：

FINPIPE_CLIENT_ID=你的client_id
FINPIPE_CLIENT_SECRET=你的api-key

保存后重启工具服务即可生效。凭证文件不要提交到任何 git 仓库。

3

重启服务（去掉 --demo）

cd finpipe-tools
PYTHONPATH="src:../openwm/src" python -m fptools.server --port 8787

页面右上角不再显示体验模式提示，即为你自己的 Key 在取数。

也可以不改文件、只用环境变量启动： FINPIPE_CLIENT_ID=... FINPIPE_CLIENT_SECRET=... python -m fptools.server

遇到问题

403 / POLICY_DENIED 体验 Key 的策略限制（部分接口不允许）。配置自己的 AppID 即可；若已有自己的 Key 仍报错，确认 Key 复制完整、未过期。
429 / 频繁限流 体验 Key 是共享池，高峰被限流属正常。配置自己的 Key 后额度独立；工具遇 429 会自动退避重试一次。
某字段显示 — 该标的此字段接口未返回（如未分红史、指标缺失）。工具不做猜测填充，缺失会显式标在该行「数据说明」。
价格略低于盘中价 现价取最新一根日 K 收盘价（体验 Key 不支持盘中快照接口）。自己的 AppID 额度允许时可换回盘中接口。
