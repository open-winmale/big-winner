配置自己的 Key

没有配置 Key 时，工具运行在演示模式——页面是真实数据的历史快照（截止日期见启动日志）， 只能看有限的示例标的。申请自己的 AppID 后即为实时全市场数据，额度充足，全程免费（非商业用途）。

1

注册开放平台，获取 AppID

打开 open.winmale.com， 微信扫码登录（注册即送免费额度）。

右上角「我的」→「开放平台」→ 左侧「我的应用」→「查看应用信息」， 复制 client_id 和 api-key（即 client_secret）。

2

写入本机凭证文件（推荐）

创建 ~/.wmshare/credentials.env，内容两行：

WMSHARE_CLIENT_ID=你的client_id
WMSHARE_CLIENT_SECRET=你的api-key

保存后重启工具服务即可生效。凭证文件不要提交到任何 git 仓库。

从旧版本升级：原 FINPIPE_* 环境变量与 ~/.finpipe/credentials.env 已随上游更名分别改为 WMSHARE_* 与 ~/.wmshare/credentials.env，请把已配置的凭证迁移到新名。

3

重启服务（去掉 --demo）

cd big-winner
PYTHONPATH=src python -m bigwinner.server --port 8787

配置凭证后启动即为实时取数；未配置凭证会自动进演示模式并在启动日志注明。

也可以不改文件、只用环境变量启动： WMSHARE_CLIENT_ID=... WMSHARE_CLIENT_SECRET=... python -m bigwinner.server

遇到问题

403 / POLICY_DENIED 确认 Key 复制完整、未过期；你的 AppID 策略需允许所调用的接口。换 Key 后立即生效，无需重启。
429 / 频繁限流 数据源小时额度用完。工具遇 429 会自动退避重试一次；等下一个整点恢复，或换一个额度充足的 Key。
某字段显示 — 该标的此字段接口未返回（如无分红史、指标缺失）。工具不做猜测填充，缺失会显式标在该行「数据说明」。
