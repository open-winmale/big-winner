# 筛选（screener）· UI/UX 设计稿 v0.5

> 快捷选股过筛 · 归属：收息佬门户 `/tools/screener/`
> 数据源：finpipe（快照 eval + qfq 日 K + 分红历史；`bonus.screen_stable_yield`）
> v0.5 定稿：不做深入分析、不做分层方法论；条件一句话介绍 + 结果列表数字即证据。
> 设计讨论中被否掉的方案（留档）：市场宽度统计卡（v0.1/v0.2）、13 个布尔筛子
> 自由勾选矩阵（v0.2/v0.3，"掷骰子"）、攒息四问分层结论（v0.4，过重）。

## 1. 定位

- 一句话：**粘贴代码、回车过筛，秒出「谁通过、断在哪」的数字列表**。
- 仅 A 股（6 位码），单次 ≤ 10 票；不做全市场扫描。
- 合规：筛选 ≠ 推荐，只描述事实；免责三处（红 banner / 页脚 / API `disclaimer`）。

## 2. 信息架构（单屏双卡）

## 3. Card 1 · 输入与条件

### 输入行
- 全宽输入框，进页自动聚焦；placeholder「粘贴 6 位代码，逗号 / 空格 / 换行分隔」
- **容错解析**：按非数字切段、只取长度恰为 6 的段（12 位连写不会误切），
  去重；输入框下灰字回显「已识别 N 只：600519 · …」
- >10 只：黄字提示已截取前 10；无识别结果：红字提示
- **回车 = 过筛**；记住上次输入与勾选（localStorage `screener_v1`）

### 条件区（息 / 势 两组，每条 = 勾选框 + 名称 + 一句话介绍）

| 组 | 条件 | 介绍原文 | 默认 |
|---|---|---|---|
| 息 | 股息率 ≥ 3% | TTM 口径，与平台高股息池一致 | ☑ |
| 息 | 派息率 30%–70% | 分红拿得出、留得住；超 100% 危险 | ☑ |
| 息 | 连续分红 ≥ 3 年 | 近年未断供（完整财年口径） | ☑ |
| 息 | 股息稳定 | 数据源判定，口径未公开 | ☐ |
| 势 | 站上 MA20 | 现价高于 20 日均线（前复权） | ☐ |
| 势 | MA60 上行 | 中期趋势向上（60 日均线今高于昨） | ☐ |
| 势 | 近 20 日涨幅 ≤ 10% | 未被短线爆炒 | ☐ |

- 条件实时联动「本次约发起 N 次查询（X 票 × Y 项）」；票数 × (3 + 稳定?1)
- 条件变更不自动重跑（额度友好），回车重新过筛

## 4. Card 2 · 结果

### 过程态
- 占位行按输入顺序固定，逐票并发请求，谁先回来谁先填充（"已回 n/m"）

### 最终态（全部返回后重排渲染）
- 汇总行：通过 X · 未通过 Y · 数据不足 Z（按股息率降序；高亮列为本次勾选条件）
- **通过列表**列：代码｜名称｜股息率｜派息率｜连续年数｜现价｜距MA20｜近20日涨幅｜股息稳定
  - 数字即入选证据；派息率 >100% 红字标「危险」；距 MA20 / 近 20 日涨幅
    红涨绿跌（本页唯一红绿语义）；✓ 蓝色 / ✗ 灰
- **未通过折叠区**（`<details>`）：代码｜名称｜未过条件（顿号连接）｜该条件数字
- **数据不足**：进折叠区，原因 = 取数错误原文（绝不冒充未通过）
- 空态：「粘贴代码后回车，结果会出现在这里」

## 5. 取数与口径（后端）

| 数字 | 来源 | 说明 |
|---|---|---|
| 名称 / 股息率 / 派息率 | 1 次 eval（`$NAME` / `$BONUS_RATE_TTM_LAST` / `$BONUS_TTM_RATE_LAST`，与透视表同源指标码） | 小数，渲染层转 % |
| MA20 / 距MA20 / MA60上行 / 近20日涨幅 | `kline.query_bars_adj(65, adj=qfq)` 本地算 | 简单均线；根数不足该字段为 None |
| 连续年数 | 分红历史本地倒推（完整财年）；最新报告期早于前年 = 断供记 0 | 口径同透视表 |
| 股息稳定 | `bonus.screen_stable_yield`（勾选才取，+1 次） | 数据源口径，未公开 |

- 缺失显式：取数失败 → 该字段 None → 条件记「数据不足」；真实空分红表 = 0 年（未通过）
- passed 三态：True 全过 / False 有断点（列出条件+数字）/ None 数据不足
