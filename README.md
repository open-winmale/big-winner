# 收息佬（big-winner）

> A 股 / 港股持仓收息、分红日历与记账 · **v1.1.0** ·
> [GitHub](https://github.com/open-winmale/big-winner)
>
> 一组围绕 A 股 / 港股持仓与分红的小工具。每个工具一个独立网页，数据来自
> [finpipe](https://github.com/open-winmale/finpipe)，只做事实与统计聚合。

## 快速开始（两个工具各自独立启动，互不影响）

```bash
# 1) 安装 finpipe（数据依赖）
git clone https://github.com/open-winmale/finpipe.git && pip install -e ./finpipe

# 2) 启动任一工具（单端口，零依赖；也可同时开两个）
cd big-winner
PYTHONPATH=src python -m bigwinner.shouxi    # 收息佬 → http://127.0.0.1:8787
PYTHONPATH=src python -m bigwinner.bigly     # 必赢佬 → http://127.0.0.1:8788
```

**没有凭证也能先看效果**（内置样例数据，不联网）：

```bash
PYTHONPATH=src python -m bigwinner.bigly --demo
```

> `python -m bigwinner.server` 为兼容别名，等价于收息佬入口。

配置自己的 AppID（内置体验额度是共享池，容易 429）：

```bash
export FINPIPE_CLIENT_ID=...
export FINPIPE_CLIENT_SECRET=...
# 或写入 ~/.finpipe/credentials.env
```

## 必赢佬 · 算法与安全边界说明

**估值通道**（与平台 web「估值通道」算法同源，借鉴其公开实现）：在 PE/PB 坐标上画
**均值 ± Nσ** 通道——σ 为窗口内估值序列的**总体标准差（÷N）**，下轨截 0（估值倍数
不为负）；−2σ 为低估线、+2σ 为高估线，另有 ±1σ 内线与均值/中位参考线。当前位置以
z=(current−avg)/σ 描述，分五档，并给出 ±2σ 通道内交易日覆盖率与历史分位。
**窗口上限 3 年**（1y/2y/3y）。数据来自 finpipe `cli.valuation.hist_stats`
（与平台同源的宿主 HIST_STATS）；亏损期 PE 无数据、净资产为负期间不参与统计。

**买卖点换算**：`价格 = 现价 × 目标倍数 / 当前倍数`（线性，隐含口径内 EPS/BPS 恒定）。
最低/最高两种来源：① 估值数据——通道低估线/高估线（默认）；② 用户估计——自填目标
PE/PB 倍数（如 PE 12/25、金融股 PB 0.8/1.0）。

**安全边界**（全部为描述性统计，工具不会阻止、也不会建议）：
- 高位警示：z≥+1 或历史分位 >70% 时显著提示「当前处于历史高位区」；
- **高位介入回撤统计**：窗口内位置分位 ≥ 当前分位的全部交易日作为假想买点，
  各自此后最大回撤的中位/最差（「过去 3 年，在相似或更高位置介入，此后最大回撤
  中位 -X%、最差 -Y%」）；
- 止损参考：窗口最低价；未设止损时回拨结果固定显示「无止损最差浮亏」。

**拨测规则**：日 low≤买点触发买入（成交 min(open, 买点)）；持仓日 high≥卖点止盈
（max(open, 卖点)）、low≤止损止损（min(open, 止损)）；同日双触发按保守先止损；
T+1 买入当日不卖；窗口末仍持仓输出浮动收益。简化假设：不含涨跌停与成交量约束；
qfq 前复权口径。**对比基准**：长持 = 首日收盘买入持有至窗口末（不含现金收益）。

**免责声明**：必赢佬全部输出为统计描述与历史回放，不构成任何投资建议；买卖点由
你自己设定与负责。免责在页面顶部横幅、页脚与结果区三处显著呈现。

### 持仓收息透视表 · 数据契约

每个字段都对应真实接口，取不到即留空并显式标注，不做猜测填充：

| 字段 | 来源 | 口径 |
|---|---|---|
| 现价 | `kline.query_bars(sym, 1)` | 原币；港股必须 `_raw=True`（HK volume 已是股，常规模式会触发手/股守护） |
| 股息率 / 派息率 | `bonus.snapshot_yield_ttm` / `snapshot_payout_ttm` | 小数；按市场分组批量取数 |
| 每股股息 | `indicator.metrics` → `$DPS_TTM_LAST_REAL` | 报价币种（港股 HKD） |
| 每股利润 | `indicator.metrics` → `$EPS_NPTS_TTM_LAST` | 财报币种（平台港股统一为 CNY） |
| 股息率 10 年分位 | `$PCT_BONUS_RATE_TTM_10Y_LAST` | 小数（深度模式） |
| 连续分红年数 | `bonus.query_list` 历史行本地倒推 | 年（无现成指标，深度模式） |
| 港股汇率 | `$CR_HKD_LAST` | HKD→CNY，仅用于组合合计 |
| 分红事件（日历） | `bonus.query_list`（`_raw=True`，按市场批量） | 状态/分红类型/股权登记日/除权日/到账日/dps |
| 最近持仓 | SQLite `position_sets` | 打开页面自动载入最近一份档案 |
| 高股息池（无持仓） | `wm-screen-index` conditions（`$BONUS_RATE_TTM_LAST >= 0.03`） | 观察池，只列已公告事件 |

**港股取数**：必须用 `market="hk"` 的 client + **5 位裸码**（如 `00700`）。
用默认 CN client 传 `hk.00700` 时，价格能正常返回（kline 内部会归一），但分红库会拼成
`hk.bonus.PROPS.HK.00700` 而查不到（真实 key 是 `hk.bonus.PROPS.00700`），指标层也会报错——
这就是"港股只有价格、没有分红/EPS"的根因。工具内部用 CN/HK 双 client 自动路由。

**币种纪律**：逐行金额保留报价币种（A 股 CNY、港股 HKD），组合合计统一折算为 CNY；
取不到汇率时该票不进合计并显式提示，绝不把 HKD 与 CNY 直接相加。

**调用量**：价格 1 次/票；股息快照 2 次/市场（失败才降级逐票）；指标标准模式 1 次/票、
深度模式再加 1 次历史/票。结果有 5 分钟 TTL 缓存。

### 分红记账 · 红利税口径

- A 股个人投资者差别化红利税，按**买入日→除权日**持有时长估算：
  ≤1 个月 20%；1 个月–1 年 10%；>1 年 0%（现行政策暂免）。
- 港股通/H 股默认 20% 预扣；本地券商、红筹等口径不同时，可在页面上按
  单票 / 年度 / 统一税率覆盖。港股不套用 A 股持有期分档。
- 未填买入日按 20% 保守估算并标「估算」；买入日之前的除权记录不计入。
- 税源优先级：单票覆盖 > 年度覆盖 > 统一税率 > 自动规则。
- 实际税额在卖出时由券商结算，本工具给的是估算值。

### 分红质量 · 方法论（v1.1）

参考 Simply Safe Dividends（多因素分档、行业模板）、Seeking Alpha（安全与
连续性分项）、分析框架（特别分红剔除）的公开思路，**不做单一黑箱安全分**，
改为双轴 + 硬旗标，所有权重公开可复现。复用平台已验证阈值
（分红率 30–70% 健康、>100% 危险、OCF/NP≥0.8、资产负债率对比行业）。

**范围纪律（数据不满足的不做）**：

- 只对 **A 股非金融**评分；银行/保险/证券（FCF 不适用）与港股
  （分红率/FCF 存在汇率与 TTM 重复计算口径问题）只展示指标并标注原因。
- 实控人/机构/北向/质押、分红政策文本、回购金额、行业分红率均值：
  SDK 无稳定数据，一律不纳入；页面上显式说明。
- 缺失显式化：核心指标缺失的票不评分（`核心数据缺失`），绝不静默填 0。

**口径**：

- 分红率 = 现金分红 ÷ 归母净利润（股息率 = 每股股息 ÷ 股价，两者不同）。
- 覆盖统一用净利润做桥，避免分红币种与报表币种混算：
  `OCF 覆盖 = (经营现金流TTM ÷ 归母净利TTM) ÷ 分红率`，
  `FCF 覆盖 = (自由现金流TTM ÷ 归母净利TTM) ÷ 分红率`。
- 连续分红年数、削减（>30%）、特别分红：从原始分红行按**完整财年**归集
  （排除取消/否决/不分配与未走完的当年；特别分红不计入经常性口径）。

**支付能力（0–100）**：现金流覆盖 35%（FCF 60% + OCF 40% 加权，
≥2x/≥1.5x/≥1x 分档）+ 分红率纪律 25%（30–70% 满分，>100% 零分）+
资产负债 20%（对比行业 3 年均值，非金融再看有息负债率/速动比率）+
盈利稳定性 20%（OCF/NP、3 年最低 OCF、净利同比）。分档：≥80 强、
60–79 中、40–59 偏弱、<40 弱。

**分红意愿（A–D）**：连续性 55%（≥10 年满分、5–9 年 80%、3–4 年 55%…）+
分红率趋势 30% + 分红金额/特别分红 15%（近两年削减超 30% 记 0）。

**硬旗标**：分红率超 100%、分红超过经营现金流/自由现金流、高股息陷阱
（股息率 ≥6% 且支付能力 <50）、连续分红 <3 年、近两年削减、净利润或
经营现金流为负、特别分红、核心数据缺失。

**置信度**：高（指标齐全且 ≥3 年历史）/ 中（缺 1 项或含特别分红）/
低（核心缺失）；低置信度不参与组合平均。

**取数成本**：每票 1 次自定义 eval（30 个目录指标 + 年度分红率/金额/股息率
序列）+ 每市场 1 次分红历史批量；30 只约 32 次 HTTP，5 分钟缓存。

### 分红持续性分析 · 每票可视化

- 页面上**每只股票**（持仓透视表、分红日历事件行、高股息池、质量表）都有
  「分红持续性分析」按钮，点击弹出可视化弹层；不依赖持仓，市场池的票也能看。
- 弹层内容：档案（名称/行业/**企业类型**/上市日期/现价）→ 支付能力
  **分项得分条**（现金流 35/分红率 25/负债 20/稳定 20，按得分率填充、权重
  公开）→ **覆盖条**（OCF/FCF，1.0x 基线标记）→ **近 5 年分红柱状图**
  （分红率 + 每股分红，特别分红另列）→ 旗标与下一次分红事件。
- 金融股/港股：弹层显示档案与已有指标 + 不评分原因；企业类型仅 A 股提供。
- 每票约 4–6 次 HTTP，5 分钟缓存。

### 收息驾驶舱 · 分红日历

- **打开即用**：自动载入最近保存的持仓（`position_sets` 按 `updated_at` 取最新），
  不用每次重新搜索；「换一份」可切换档案。
- **未来 7/30/90/365 天**：股权登记日、除权日、到账日、方案状态（预案/实施/已执行）、
  税前/税后现金；预案单独标注，不计入「今年已收」。
- **预案待定**：董事会/股东大会预案即使没有确定日期也单独成组并计数；
  市场视图把它排在已到账之前，先用“未来有没有分红公司”回答用户。
- **持仓没有未来事件时**：自动加载市场高股息池的待除权/预案预览（前 6 条），
  不用再点按钮；首次约 10–25 秒（选股接口），之后 10 分钟缓存。
- **取数成本**：持仓/关注池用 `bonus.query_list` 按市场批量（一次 HTTP），
  保留原始 `状态/分红类型/股权登记日`；5 分钟缓存。
- **无持仓**：走平台高股息选股池（`wm-screen-index`，股息率 ≥ 3%），
  再批量查池内已公告的分红事件。**这不是全市场逐票扫描**；全市场日历需要
  平台侧物化 `bonus.CALENDAR` 日期表。该视图依赖 `wm.sh` 门面；没有配置时，
  持仓/关注池日历与透视表仍可正常使用。
- **年息目标**：TTM 年息 / 目标进度，以及按当前成本股息率估算还差多少本金。

## 设计原则

1. **单位纪律** —— 内部一律基础单位（比率小数、金额元），只在渲染层转百分比。
   杜绝 `0.0396` 被读成 `0.04%` 这类量级错误。
2. **缺失显式化** —— 取数失败或返回空，字段留 `—` 并记入该行「数据说明」，
   汇总展示数据完整度 `n/m`。绝不静默填 0。
3. **组合口径正确** —— 组合股息率按**市值加权**，不是各票算术平均；
   股息率/成本股息率只对有完整配对的标的计算，缺价/缺成本的票不污染分子分母。
4. **币种不混算** —— 逐行保留原币，组合合计统一折 CNY；缺汇率时宁可置空并提示。
5. **税口径透明** —— 税额是估算值，税源（自动/单票/年度/统一/港股默认）逐笔标注，可覆盖。
6. **可测试** —— 取数层 `Fetcher` 可替换，`FakeFetcher` 让全部逻辑离线可测。
7. **合规红线** —— 只描述事实（"CR3 = 61%"），不输出指令（"应分散持仓"）。

```
src/bigwinner/

    ledger.py                # 分红记账：税档 / 覆盖 / 年度汇总
    calendar.py              # 分红日历：事件解析 / 税后现金 / 年息与目标
  web/
    index.html               # 工具总览
    dividend_xray.html       # T1 页面（驾驶舱 + 透视表 + 账本）
    assets/base.css, app.js
tests/
  test_dividend_xray.py
  test_dividend_quality.py
  test_server_quality.py
  test_ledger.py
  test_fetchers.py
  test_export.py
  test_calendar.py
  test_server_ledger.py
  test_server_calendar.py
```
